# 配布EXEがFigmentum法線計算で即終了する

- 日付: 2026-09-09
- 状態: 起動修正を実機確認済み、統合後の再検証待ち
- 対象: Windows配布版、commit 1c031f4a、Revisor PR 1627–1629
- ユーザー報告: 起動直後に終了する

## 証跡

ユーザーがコンソールで確認した出力:

```text
[konbini] startup failed: Figmentum polygonize produced a degenerate vertex normal
```

配布時にはReleaseビルドとZIP資産ハッシュのみ確認し、ユーザーの当時のテスト禁止指示に従い起動していなかった。
その後ユーザーが起動確認と100倍速のゲームクリア検証を明示指示したため、今回から提出条件とする。

## 原因

固定版Figmentumのmarching cubesは、SDFの値が格子点の等値面に一致すると、その格子点へ交点を寄せる。
その結果、三角形の頂点が重なることがある。KonbiniDominant側は全三角形をそのまま法線計算に渡し、
面積ゼロの三角形の頂点でも長さゼロの法線を正規化しようとして例外終了していた。
contentの読込みと都市メッシュ生成より後の処理であり、事前計算ファイルの存在を要求したエラーではない。

## 修正

- アダプター内で面積ゼロの三角形を除去する。
- 使用されなくなった頂点を除去してindexを詰め、有効な面だけから法線を計算する。
- 非有限値、範囲外index、面が全て退化する不正メッシュは引き続き明示エラーにする。
- メッシュ変換結果が変わるためgeometry cache schemaを更新する。
- 計算データを読み込めない場合とgeometry異常は別の診断として扱う。
