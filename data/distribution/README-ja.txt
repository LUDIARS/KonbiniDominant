KonbiniDominant — マウス／タッチ操作版
Phase 1–4 + 11種のスキル
Windows x64 開発版

遊び方
ZIPを展開して konbini_dominant.exe を開きます。
shaders と data フォルダは実行ファイルの隣に置いてください。
Vulkan に対応した GPU とグラフィックスドライバーが必要です。

最初にコンビニを1種類選びます。そのプレイ中に置けるのは選んだ種類だけです。
画面のカードをクリック／タップして、最初のチェーンを選びます。
初期資金は5店舗分。Phase 1はビルのない16×16の土の地面です。空きマスを1回クリック／タップすると出店します。
1店舗は正方形の1マス。同じチェーンを辺で隣接させると、外観と看板がつながって広がります。
斜め・別チェーン・別階・別次元とは連結しません。Phase 2以降はBUILDや長押しで上に積めます。
地図の空いている部分をドラッグするとカメラ移動、2本指ピンチで拡大・縮小します。
自社3店舗で三角形を作ると、内部の集客力と頂点店舗の収益が増えます。
敵店舗を三角形で3秒間囲むと破壊できます。自分の店舗も同じルールで破壊されます。
赤い輪は包囲の予告です。相手の三角形を崩すと解除されます。

ゲームの流れ
Phase 1：都市支配。敵全滅＋人口の60%以上を獲得、または5分経過で次へ。
Phase 2：縦積みと信仰。どれか1施設を256階まで積む、または3分経過で次へ。
  敵店舗の上にも積めます。上階ほど高価で、直下に店舗が必要です。
  下階を破壊されても上階は浮いたまま残ります。地上の跡地には再出店できます。
  信仰100で商圏の影響力が倍増。ACTIONS → IMAGE のイメージ戦略で自社の信仰を増やせます。
Phase 3：2つの別次元を攻略。ACTIONS → NEXT WORLD で次元を切り替えます。
  敵店舗の信仰が100になったら、その階を選択して ACTIONS → INVERT で反転。
  D0の同じ区画・同じ階に自店舗があると対消滅し、敵次元が崩壊します。
  反転店舗は紫色です。位置対応は同じ都市の区画で、施設IDの数字は次元ごとに異なります。
  敵店舗を全滅させ、自店舗で占拠しても攻略完了になります。
  攻略後はD0に30秒の収益・信仰ボーナス。自分の別次元店舗も崩壊時に失われます。
Phase 4：中央にWARNINGを5秒表示してからアイオーン出現。
  アイオーンは0.4秒ごとに各次元へ出店します。
  アイオーンの三角形が成立するとMaxValueの4秒予告。三角形を崩すと解除できます。
  予告が満了した次元は崩壊します。防犯カメラでは次元崩壊を遅らせられません。
  5秒ごとに過去の店舗配置を別区画へ貼り付け、既存店舗を上書きします。
  ACTIONS → ESCAPE で新しい次元に逃げて1店舗を建設。費用は1000＋建設費、再使用は3秒後です。
  30秒後まで、どこかの生きている次元に自店舗が1つ残れば勝利。
  ボス戦で自店舗が全滅すると即敗北です。
ボス戦前も、自店舗ゼロかつ再建資金不足で敗北します。結果画面の PLAY AGAIN で最初から再挑戦できます。

レベルアップ
集客から経験値を獲得し、レベルアップ時に最大3択からスキルを選びます。
画面の候補カードをクリック／タップして決定。選択中はゲーム時間が停止します。
スキルは最大6種類、各5段階。同じものを選ぶと強化されます。
6種類を揃えた後は、所持スキルの強化だけが候補に出ます。
HELPの説明表示で取得済みスキルのレベルを確認できます。

スキル（1段階あたり）
多言語スタッフ / MULTILINGUAL STAFF：信仰成長＋1
宅配便 / DELIVERY：商圏の半径＋8%
カッフェマシン / COFFEE MACHINE：10秒ごとに1店舗あたり20の売上、32店舗まで
パンとドーナツ / BREAD AND DONUTS：自店が対応する住民の人口回復＋2
ホットスナック / HOT SNACKS：10秒ごとに3秒間、範囲内の集客力＋1
こだわり素材 / QUALITY INGREDIENTS：収益＋10%
居抜き出店 / REUSED SHOP：建設費－8%
防犯カメラ / SECURITY CAMERA：包囲されてから破壊までの猶予＋1秒
深夜シフト / NIGHT SHIFT：周期スキルの間隔－8%
上底テクニック / RAISED BOTTOM：収益＋20%、信仰成長－1
怪音波 / MIND WAVE：15秒ごとに範囲内の住民を一時的に自店へ誘導。
  効果時間は2秒＋レベル×0.5秒。敵の店が近くても自店へ呼び込みます。
周期スキルは取得直後のゲーム進行時にも発動します。
上底の信仰低下は多言語スタッフなどで補えます。信仰は0～100の範囲です。

操作（キーボードなしでプレイ可能）
チェーン／スキル：画面のカードをクリック／タップ
区画選択：地図の区画をクリック／タップ
BUILD：選んだ区画に出店
BUILD長押し：0.35秒後から連続建設（Phase 2以降）
  建設成功後は次の空き階へ移動します。
  既存店舗の上に建て始める場合は FLOORS → NEXT FREE を使います。
DESELECT：選択解除
地図を左ボタン／1本指でドラッグ：カメラ移動
ホイール／2本指ピンチ／ZOOM - / +：拡大・縮小
FLOORS：FLOOR - / +で階移動、NEXT FREEで次の空き階、GROUNDで地上
ACTIONS：IMAGE（信仰強化）、NEXT WORLD（次元切替）、INVERT（反転）、ESCAPE（逃走）
BACK：通常の操作欄へ戻る
PAUSE / RESUME：一時停止・再開
HELP / HIDE HELP：説明と所持スキルの表示切替
PLAY AGAIN：結果画面から再挑戦
ウィンドウの閉じるボタン：終了

ボタンは離したときに確定します。指やマウスをボタン外へ動かすと取り消します。
暗いボタンは条件未達です。説明欄や操作欄へのタップは背後の区画へ通りません。
連続建設中にレベルアップしたら強化を選び、改めてBUILDを押してください。
小さい画面ではボタンの列数と全体サイズが変わります。

補助ショートカット
1 / 2 / 3：チェーン／スキル選択、右クリック / Esc：選択解除
WASD / 中ボタンドラッグ：移動、Q / E：階移動、F：空き階、G：地上
Space長押し：連続建設、C：イメージ戦略、Tab：次元切替、I：反転、X：逃走
P：一時停止、F1：説明表示、R：結果画面から再挑戦

画面と文字
既定の画面は1280×720（横画面）。操作ボタンと文字を小型化しています。
HUDと店舗看板はGoogle FontsのRoboto Monoを輪郭の三角形で描画しています。

この配布物について
Phase 1–4と11種のスキルを、マウス／タッチで操作する開発版です。
タッチ対応はWindowsのタッチ画面が対象です。Android / iOS / Web版ではありません。
Windows Releaseビルドとアーカイブの整合性を確認しています。
配布前に、同じEXE・設定データ・shaderを使った起動と100倍速設定での自動クリアを確認します。
検証結果と実測時間はBUILD_INFO.jsonのnativePlaytestに記録しています。
通常起動は1倍速・手動操作です。テスト用の自動操作設定は同梱しません。
Windowsの初回検証ではVICTORY画面を確認済みです。端末上のタッチ・ピンチ、DPI切替、操作感、難易度、256階時の実行性能は未確認です。
強化の組み合わせ進化、永続強化、音声演出は今回含めていません。
BUILD_INFO.jsonにコミットと同梱ファイルのハッシュを記録しています。
