KonbiniDominant — Phase 1
Windows x64 / 5分間のコンビニ都市支配ゲーム

遊び方
ZIPを展開して konbini_dominant.exe を開きます。
同梱の shaders と data フォルダは実行ファイルの隣に置いてください。
Vulkan に対応した GPU とグラフィックスドライバーが必要です。

操作
1 / 2 / 3 : チェーン選択
左クリック : 施設を選択。同じ施設をもう一度クリックして出店
右クリック / Esc : 選択解除
WASD / マウス中ボタンドラッグ : カメラ移動
ホイール : 拡大・縮小
P : 一時停止・再開
F1 : 操作説明の表示切替
R : 結果画面から再挑戦

ゲームの流れ
最初は5店舗分の資金があります。商圏内の住民を顧客にし、定期収益を
次の出店に使います。同じチェーンの近い3店舗で三角形を作ると、
内部への影響力が増し、頂点の店舗の収益が1.5倍になります。

敵店舗を三角形で3秒間囲み続けると自動的に破壊します。
自店舗も同じルールで破壊されます。赤い予告の輪が消える前に、
相手の三角形を崩すと包囲を解除できます。
破壊された跡地には再出店できます。

敵2社は同じ資金・出店ルールで動きます。
出店の間隔は当初6秒で、4分かけて2秒まで短くなります。
商圏が重なる場所は、より多くの店舗で覆うチェーンが顧客を獲得します。
同点なら現在の顧客先を維持します。

勝敗
・敵店舗を全滅させ、現在の都市人口の60%以上を顧客にすると勝利。
・5分経過した時は顧客人口が最大のチェーンが勝利。
  自分を含む首位同点は引き分け。敵だけが首位の場合は敗北。
・自店舗がゼロで、再出店する資金もない場合は敗北。
・終了後に R を押すと、チェーン選択からやり直せます。

HUD
S : 店舗数 / C : 顧客人口 / T : 三角形の数
ENEMY BUILD INTERVAL : 敵の出店間隔
DANGER : 包囲されている自店舗の数
